# Dog Breed Classification

This project implements an end-to-end MLOps pipeline for dog breed classification, including

- data preprocessing
- model training
- model evaluation
- ONNX model export
- BentoML deployment
- frontend application
- data drift detection

In the `Documentation` section, you can find detailed information about the core classes and functions used in the project group into the following categories:

- Data Preprocessing
- Model Training
- Model Evaluation
- Model Deployment
- Drift Detection
